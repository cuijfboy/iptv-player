# 敏感信息守护白名单 / allowlist for tools/ci/sensitive-info-guard.sh
#
# One entry per line:   <ERE over "path:line:text"><TAB><reason>
#   - the PATTERN is an extended regex matched against the whole hit line, so narrow it with a
#     path prefix or with the exact harmless value;
#   - the REASON is mandatory and is printed every time the entry suppresses a hit, so a
#     suppression is never silent;
#   - `#` at the start of a line is a comment, blank lines are ignored.
#
# Keep this list short and boring. An entry that says "it was leaking, but we allow it" is how the
# guard quietly dies; an entry is only acceptable when the value could not identify anything.
