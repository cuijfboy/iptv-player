### 2.2 Spike（用数据定调）

| # | 验证项 | 方法 | 通过标准 | 结论用途 |
|---|---|---|---|---|
| **S1** | Media3 播放能力（**口径：Media3 复测**） | 取 20 个已验证频道循环播放，用 **Media3** 复测成功率/起播耗时/失败特征，并与 dsh 的 Android MediaPlayer 深探结果对照 | Media3 成功率 **≥90%**、平均起播 **≤3 s**，并给出 `Media3 成功率 − MediaPlayer 成功率` 差值 | 决定 Media3 是否为主引擎（dsh 结果仅作候选集与对照基线） |
| **S2** | **音频编码 × 透传/软解矩阵** | 对 {AAC / MP2 / AC3} × {透传 / 软解} 各组合挑频道实测出声，对比 AAC 频道 | 每个组合标注"可出声/不可"；AC3/EAC3 不可透传时给出软解方案与可行性 | 决定默认透传与降级顺序（探测 → 直通 → 关透传重试 → 切源）与是否引入 libVLC（AC3/EAC3 占比 **≥5% 且不可透传**才引入；当前基线 0.3%） |
| **S3** | EPG 网格性能（**限定为原型**） | Canvas 原型绘制 658 台 × 6 h，滚动采样帧耗时；P0 只交**可丢弃代码 + 帧耗时数据结论** | **≥50 fps**，内存增量可控 | 决定自绘方案是否成立；产品级网格仍属 P3-1 |
| **S4** | 构建链 | 空工程 → 签名 APK → adb 安装启动 | 全链路通过 | 决定后续构建方式 |
| **S5** | 换台体验 | 连续换台 30 次（复用引擎实例） | 平均 ≤3 s，无内存增长 | 决定引擎复用策略 |
| **S6** | 冷启动 | 从点击图标到可看 | ≤5 s | 决定启动期预加载策略 |

## 8. 发布与交付流程

```
./gradlew clean testDebugUnitTest lint assembleRelease
adb connect 192.168.x.x:5555
adb install -r app/build/outputs/apk/release/app-release.apk
adb shell am start -n ilab.iptv.player/MainActivity
```

> **入口（BUG-001 修正）**：组件入口为 `ilab.iptv.player.MainActivity`。原文档误写 `ilab.iptv.player/.ui.MainActivity`，与 APK 清单实际入口不符，照抄会报 `Error type 3 … does not exist`。

| 项 | 约定 |
|---|---|
| 版本号 | `versionName` 语义化（0.x 开发期）；`versionCode` 单调递增 |
| 签名 | `keystore/release.jks`（入仓）；口令 `local.properties`/`keystore/local.properties`（不入仓） |
| 产物 | GitHub Actions 上传 Release APK（P0 后可加） |
| 提交规范 | `feat/fix/docs/refactor/test/chore(scope): subject`；每阶段至少一次提交 |
| 文档同步 | 架构或决策变更必须同步更新 `docs/`（本次起执行） |

> **产物说明（BUG-004，god 裁决 2026-09-21）**：APK **不是字节可复现构建**——同一源码多次构建 payload 一致，但签名/`META-INF` 元数据不同，整包 SHA256 会变。因此**报告中出现的 SHA256 只标识单次构建产物**，不作为发布指纹或回归比对基线。

## 9. 风险登记册（执行视角）

| # | 风险 | 触发信号 | 应对 | 责任阶段 |
|---|---|---|---|---|
| R1 | 电视不在线/ADB 不通 | `adb connect` 失败 | 降级为"只产出 APK，用户自行安装"；先做离线可验证的部分 | P0 |
| R2 | Gradle/AGP 与本机不兼容 | 同步失败 | 以 Android Studio 向导生成的版本组合为准；必要时装 cmdline-tools 补 platform | P0 |
| R3 | AC3 无声 | S2 失败 | 优先 AAC 源 + 软解扩展 + libVLC 兜底 | P0 |
| R4 | 老 SoC 卡顿 | S3/验收 fps 不达标 | 减小可视区、缓存文本布局、降低动画、必要时降级为"列表 + 精简网格" | P0/P3 |
| R5 | EPG 覆盖率不达标 | `EPG_COVERAGE` < 60% | 多源 + 别名表 + 手动绑定；允许无 EPG 降级 | P3 |
| R6 | 公共源大面积失效 | `SRC_SELECT` 入选数骤降 | 故障转移 + 复检 + 提示用户加源 | P2 |
| R7 | 刷新拖慢播放 | `PLAY_STALL` 与刷新时间重叠 | 播放避让（并发减半/暂停） | P2 |
| R8 | 仓库公开导致隐私泄露 | 提交前检查 | 文档脱敏流程 + `.gitignore` 覆盖 local.properties 与导出包 | 每次提交 |
