## 2. 新增的 4 个事件码

| 事件码 | 级别 | 分类 | 触发点 | 关键字段 |
|---|---|---|---|---|
| `SERVICE_PLAYBACK_START` | INFO / ERROR | `SERVICE` | 播放前台服务**进入**前台（P1-7 第 1–2 项） | `channelId`、`streamId`、`phase`、`result`（`ok`/`failed`） |
| `SERVICE_PLAYBACK_STOP` | INFO | `SERVICE` | 播放前台服务**离开**前台 / 停止（收尾） | `reason`、`channelId`、`streamId` |
| `PLAY_FOCUS_CHANGE` | INFO | `PLAYER` | 音频焦点每次变化（P1-7 第 3 项） | `reason`、`pause`、`resume`、`duck`、`restoreVolume`、`abandonFocus` |
| `PLAY_NET_RETRY` | INFO | `PLAYER` | 网络恢复触发的重试（P1-7 第 5 项） | `attempt`、`channelId` |

登记位置：`core/common/.../EventCodes.kt`（`PLAYER` 段加 2 个、`SERVICE` 段加 2 个），并加入 `ALL` 集合（`isRegistered()` 由 `ALL` 派生，CI 的「禁裸码」守护因此能拦住这 4 个码的字面量）。

## 3. 发出点

新增发射器 `feature/player/.../PlaybackSystemEvents.kt`（接 `Logger` 门面，与 `core:player` 的 `PlaybackEventLogger` 同款式：码在一处、字段名在一处、可被 JVM 单测钉住）。三个链路各接上它：

| 事件码 | 发出点（文件:类） | 说明 |
|---|---|---|
| `SERVICE_PLAYBACK_START` | `feature/player/.../PlaybackService.kt` · `apply()` 的 `startForeground` 分支 | `ServiceCompat.startForeground(...)` **成功发 `result=ok`；抛异常发 `result=failed` 并带异常**（API 31+ 后台起前台被拒的唯一痕迹），`onUpdateNotification` 路径不重复发 |
| `SERVICE_PLAYBACK_STOP` | 同上 · `stopSelf` 分支 + `onDestroy()` | `stopSelf` 发 `reason=phase-<phase>`；服务在**前台**被销毁（系统回收 / 任务移除 / `stopService`）发 `reason=service-destroyed`，保证「起 / 停」成对 |
| `PLAY_FOCUS_CHANGE` | `PlaybackService.onCreate` 给 `AudioFocusController` 传的 `onDecision` 回调 | `AudioFocusController.acquire()/apply()/release()` 每条决策都走 `onDecision`，**获得（`GAIN`）与失去（`LOSS`/`LOSS_TRANSIENT`/`CAN_DUCK`）都发**，`reason` = 焦点事件本身 |
| `PLAY_NET_RETRY` | `feature/player/.../NetworkRetryWire.kt`（真实门控路径） | 门控放行**恰好一次/次断网**时，先发码再调用 P1-5 的 `retry()`；接线在 `PlayerViewModel`（`events` + `channelId` 取 `playback.value.channelId`） |

## 4. 字段口径（排查手册要用的口径）

- **什么时候**：`LogBus` 的信封字段（`ts` / `elapsedMs` / `thread` / `sessionId`）由日志总线统一盖章；本卡没有自造时间字段。
- **为什么**：`SERVICE_PLAYBACK_STOP.reason`（哪条路径收尾）、`PLAY_FOCUS_CHANGE.reason`（哪种焦点事件）、`PLAY_NET_RETRY` 隐含「网络恢复」。
- **结果如何**：`SERVICE_PLAYBACK_START.result`（`ok`/`failed` + 失败带异常）、`PLAY_FOCUS_CHANGE` 的 5 个决策布尔（暂停 / 恢复 / 压音量 / 还原音量 / 释放焦点）、`PLAY_NET_RETRY.attempt`（本会话第几次重试）。
- **脱敏**：字段只有 id、阶段名、枚举名与布尔，**无 URL**（docs/03 §11）。守护脚本 `sensitive-info-guard.sh` 对本轮改动 **0 未放行命中**。
